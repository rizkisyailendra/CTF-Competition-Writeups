### 🎯 Kategori yang Biasa Dikerjakan
* 🌐 **Web Exploitation** — *SQLi, XSS, SSRF, IDOR, Bypass Auth, dll.*
* 🔐 **Cryptography** — *RSA, AES, Classic Cipher, Custom Crypto.*
* 🔍 **Digital Forensics** — *Network Capture (PCAP), Memory Dump, Steganography, File Carving.*
* ⚙️ **Reverse Engineering** — *Binary Analysis, Decompiling, Patching.*
* 💥 **Binary Exploitation (Pwn)** — *Buffer Overflow, Format String, ROP.*
* 🕵️ **OSINT** — *Open Source Intelligence & Digital Footprint.*
